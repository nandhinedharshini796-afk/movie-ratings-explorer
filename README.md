# Movie Ratings Explorer

A movie search and analytics app built with Python, SQL, Pandas, Streamlit and Plotly.

## Features
- Search movies by title
- Filter by genre, year range, minimum rating and minimum votes
- Charts: average rating by genre, rating trend by year, rating distribution

## Dataset
TMDB 5000 Movies (Kaggle), about 4,800 movies

## How to run
1. pip install pandas plotly streamlit
2. python step2.py (creates the SQLite database)
3. python -m streamlit run app.py
